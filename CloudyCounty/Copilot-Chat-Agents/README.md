# Microsoft 365 Copilot Chat Agent Templates

This folder contains the resources and templates required to configure Microsoft 365 Copilot Chat Agents. Each agent configuration consists of five key components: Name, Description, Instructions, Knowledge Sources, and Starter Prompts. These files are designed to guide you through creating and customizing agents to meet specific needs, streamlining workflows, and enhancing collaboration across your organization.

## [AskIFAS](AskIFAS.md)

This Agent empowers users—UF/IFAS cooperative extension agents, faculty, staff, and the public—to easily access and apply the latest, research-based information from the University of Florida Institute of Food and Agricultural Sciences. By leveraging authoritative UF/IFAS resources, it supports teaching, research, outreach, and real-world problem solving across agriculture, natural resources, human health, and Extension initiatives.

## [LCARS](LCARS.md)

This Agent is designed to assist with Star Trek-related queries, inspired by the LCARS (Library Computer Access/Retrieval System) interface. It provides a rich source of Star Trek lore and facilitates account generation with a Trek-themed twist, blending functionality with fandom in a conversational and engaging manner.

## [AltText](AltText.md)

This Agent is designed to assist users in generating alt text for images. It focuses on creating vivid, detailed, and engaging descriptions that not only capture the visual elements but also convey the story behind the scenes. The agent is tailored to ensure that every image is accessible and rich in context, making it a valuable tool for individuals who rely on alt text for understanding visual content.
